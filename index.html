🔐 Gestor de Contraseñas | Password Manager

Gestor de contraseñas seguro, rápido y moderno con CLI y GUI.

A secure, fast and modern password manager with CLI and GUI.

🇪🇸 Español • 🇬🇧 English

🇪🇸 Español

📋 Características

✅ Almacenamiento Seguro - Encriptación Fernet de extremo a extremo
✅ Dos Interfaces - CLI colorida + GUI moderna con Tkinter
✅ Generador Avanzado - Crear contraseñas con opciones personalizadas
✅ Evaluador de Fortaleza - Analiza y da recomendaciones
✅ Búsqueda Rápida - Encuentra contraseñas al instante
✅ Copiar al Portapapeles - Un click para copiar
✅ Multiplataforma - Linux y Windows sin cambios
✅ Base de Datos Local - Todo guardado en tu máquina

🔧 Requisitos

  • Python 3.8 o superior
  • pip (gestor de paquetes)
  • Linux o Windows

📥 Instalación

# 1. Clona el repositorio
git clone https://github.com/Daivis-svf/gestor-contraseñas.git
cd gestor-contraseñas

# 2. Instala dependencias
pip install -r requirements.txt

# 3. Dale permisos de ejecución (Linux/Mac)
chmod +x cli/main.py
chmod +x gui/app.py

🚀 Uso

Versión Terminal (CLI)

python cli/main.py

Características:

  • Menú interactivo colorido
  • Ver todas las contraseñas
  • Agregar nuevas contraseñas
  • Generar contraseñas automáticas
  • Buscar por nombre o usuario
  • Verificar fortaleza
  • Historial de generadas

Versión Gráfica (GUI)

python gui/app.py

Características:

  • Interfaz moderna y fácil de usar
  • Pestañas para diferentes funciones
  • Tabla de contraseñas
  • Generar contraseñas visuales
  • Búsqueda en tiempo real
  • Copiar al portapapeles
  • Diálogos informativos

📁 Estructura

gestor-contraseñas/
├── backend/
│   ├── encryption.py         # Encriptación de datos
│   ├── database.py           # Base de datos SQLite
│   ├── generator.py          # Generador de contraseñas
│   └── password_manager.py   # Lógica principal
├── cli/
│   └── main.py              # Interfaz de terminal
├── gui/
│   └── app.py               # Interfaz gráfica
├── data/                    # Datos guardados (generado)
├── requirements.txt         # Dependencias
└── README.md

🔒 Seguridad

  • Encriptación Fernet - Algoritmo simétrico seguro
  • Contraseña Maestra - Acceso protegido con hash SHA256
  • Base de Datos Local - Tus datos nunca se envían a internet
  • Sin conexión - Funciona completamente offline

💾 Primer Inicio

La primera vez que ejecutes el programa:

  1. Se te pedirá configurar una contraseña maestra
  2. Esa contraseña protege todas tus otras contraseñas
  3. Se guarda un hash seguro (no la contraseña)

Importante: Si olvidas la contraseña maestra, no habrá forma de recuperar tus datos. ¡Guárdala en lugar seguro!

🎯 Casos de Uso

  • Organizar todas tus contraseñas en un lugar
  • Generar contraseñas fuertes y seguras
  • Sincronizar contraseñas entre aplicaciones
  • Backup personal de credenciales
  • Validar fortaleza de contraseñas

⌨️ Atajos (CLI)

Tecla Acción

Enter Confirmar entrada

🐛 Solución de Problemas

"Error: No module named 'cryptography'"

pip install cryptography pyperclip

"ModuleNotFoundError" en GUI

python -m pip install --upgrade pip
pip install -r requirements.txt

No se copia al portapapeles

  • Tkinter intenta usar varios sistemas. En algunos Linux necesitas: xclip o xsel
  • Ubuntu/Debian: sudo apt-get install xclip

📞 Soporte

Si encuentras problemas:

  1. Verifica que Python 3.8+ esté instalado
  2. Reinstala dependencias: pip install -r requirements.txt --force-reinstall
  3. Abre un issue en GitHub

🔒 Security

  • Master Password - Access protected with SHA256 hash
  • Local Database - Your data is never sent to internet
  • Offline - Works completely offline

💾 First Start

The first time you run the program:

  1. You will be asked to set up a master password
  2. That password protects all your other passwords
  3. A secure hash is saved (not the password)

Important: If you forget your master password, there will be no way to recover your data. Keep it in a safe place!
